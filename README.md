+# 고양이 바구니 구조대
+
+하늘에서 떨어지는 귀여운 고양이를 바구니로 받아 점수를 얻는 간단한 웹게임입니다. HTML, CSS, JavaScript만 사용했으며 브라우저에서 바로 실행할 수 있습니다.
+
+## 게임 방법
+
+1. `게임 시작` 버튼을 누릅니다.
+2. 카운트다운이 끝나면 고양이가 하늘에서 떨어집니다.
+3. 바구니를 좌우로 움직여 고양이를 받습니다.
+4. 고양이를 받으면 10점을 얻고, 놓치면 목숨이 1개 줄어듭니다.
+5. 목숨이 모두 사라지면 게임 오버입니다.
+6. 게임 오버 화면에서 최종 점수와 최고 점수를 확인하고 다시 시작할 수 있습니다.
+
+## PC 조작법
+
+- 왼쪽 이동: `←` 또는 `A`
+- 오른쪽 이동: `→` 또는 `D`
+
+## 모바일 조작법
+
+- 화면 아래의 `◀`, `▶` 버튼을 눌러 바구니를 움직입니다.
+
+## 프로젝트 구조
+
+```text
+/
+├── index.html
+├── css/
+│   └── style.css
+├── js/
+│   └── game.js
+└── README.md
+```
+
+- `index.html`: 게임 화면과 버튼, 점수 UI를 구성합니다.
+- `css/style.css`: 귀여운 배경, 캐릭터, 반응형 레이아웃, 애니메이션을 담당합니다.
+- `js/game.js`: 게임 시작, 이동, 고양이 생성, 충돌 판정, 점수, 목숨, 최고 점수 저장을 처리합니다.
+- `README.md`: 게임 소개와 실행 방법을 안내합니다.
+
+## 사용한 기술
+
+- HTML5
+- CSS3
+- JavaScript
+- localStorage
+
+## 게임 실행 방법
+
+가장 간단한 방법은 `index.html` 파일을 브라우저로 직접 여는 것입니다.
+
+또는 로컬 서버를 사용하려면 프로젝트 폴더에서 아래 명령어를 실행한 뒤 브라우저에서 `http://localhost:8000`에 접속하세요.
+
+```bash
+python3 -m http.server 8000
+```
